# Biblioteca Escolar Moçambique — site inicial

Este repositório contém uma versão inicial do site "Biblioteca Escolar Moçambique".

O que foi incluído nesta commit inicial:

- index.html — HTML melhorado com acessibilidade básica, formulário de pesquisa e metadados Open Graph.
- style.css — estilos responsivos e foco acessível.
- script.js — pesquisa local simples (filtra os cartões) e handlers de teclado/click.
